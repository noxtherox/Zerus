## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-pick-vault-folder`
- `allow-restore-vault-folder`
- `allow-clear-vault-folder`
- `allow-pick-external-notes`
- `allow-pick-files`
- `allow-pick-external-folder`
- `allow-open-file`
- `allow-cloud-ai-status`
- `allow-configure-cloud-ai`
- `allow-connect-openrouter`
- `allow-cloud-ai-models`
- `allow-generate-cloud-ai`
- `allow-stop-cloud-ai`
- `allow-start-speech-recognition`
- `allow-speech-recognition-progress`
- `allow-stop-speech-recognition`
- `allow-cancel-speech-recognition`
- `allow-device-name`
